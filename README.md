Kami menggabungkan pemahaman proses bisnis dengan software engineering untuk menghasilkan solusi yang efektif, scalable, aman, dan mudah dikembangkan dalam jangka panjang.

## Tentang Repositori

Repositori ini berisi source code **frontend** [ALDEF Fulfillment Center](https://wms.aldeftech.com), sistem manajemen gudang (WMS) multi-klien dan multi-gudang. Aplikasi berupa single-page application React yang terhubung ke REST API di repositori [WMS-BE](https://github.com/aldef-deni/WMS-BE). Hasil build berupa file statis, sehingga dapat di-hosting tanpa Node.js di server.

Fitur utamanya meliputi:

- halaman login dengan tombol akun demo satu klik;
- dashboard operasional dengan KPI, grafik aktivitas tujuh hari, antrean, SLA, kapasitas gudang, dan peringatan stok;
- layar inbound, persediaan, pesanan, picking, packing, shipping, mutasi, retur, stock opname, dan adjustment;
- input scanner bertipe keyboard untuk scan lokasi, SKU, dan resi;
- tabel dengan pagination, pencarian, filter, serta urutan terbaru/terlama;
- filter cepat per gudang dan per klien di seluruh workspace;
- invoice, biaya layanan, laporan, dan unduhan CSV/Excel/PDF serta label pengiriman;
- portal klien dengan menu yang disesuaikan hak akses;
- administrasi pengguna, role & permission, pengaturan, dan audit log;
- halaman profil: data pribadi, foto profil, ganti password, sesi aktif, akses, dan aktivitas;
- tampilan responsif untuk desktop dan perangkat mobile.
