# ALDEF Frontend

React, TypeScript, Vite dan Tailwind untuk dashboard operasional dan portal klien.

Panduan lengkap ada di [README proyek](../README.md). Jalankan `npm run dev` pada port 5173 dengan backend port 8000 dan MySQL 3307. Proxy `/api` dan `/sanctum` ada di `vite.config.ts`.

Verifikasi: `npm run typecheck`, `npm run test`, `npm run build`. Logo asli ada di `public/aldef-logo-2026.png`. Entry aplikasi adalah `src/main.tsx` → `src/Workspace.tsx`.
